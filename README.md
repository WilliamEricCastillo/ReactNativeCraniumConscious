# Cranium Conscious (React Native)

**Cranium Conscious** is a cross-platform mobile app built with **React Native** that focuses on mental wellness and user self-reflection.  
The app includes features like mood tracking,and journaling to support mental health over time.  

> 🧠 This project is **still in development**. The goal is to make it **cross-functional**, expanding from a mobile application to a full web application in the future.  
> 💡 **Future updates** will include **gamification features** for journal entries and streaks to motivate consistency and engagement.

### More Details on the Project

**React Native Mobile Application**  
🔗 [GitHub Repository](https://github.com/WilliamEricCastillo/ReactNativeCraniumConscious)  

- Developed a React Native mental health app with key features for user journaling and mood tracking.  
- Implemented Firebase authentication and database services, ensuring secure login and data management.  
- Designed a mood chart to help users visualize daily mood fluctuations and identify patterns and triggers.  
- Added a calendar feature to enable users to enter and review past journal entries.  

---

## 📱 Features

- **Mood Tracker** – users can log mood over time and see patterns  
- **Journal & Notes** – write and revisit personal reflections  
- **Analytics & Visualization** – charts or graphs of user mood trends  
- **Gamification (Coming Soon)** – streak tracking and achievement badges for journaling consistency  

---

## 🧩 Tech Stack & Tools

- **React Native** (JavaScript / TypeScript)  
- **Expo** (for build and development)  
- **State Management** – Redux or Context API  
- **Navigation** – React Navigation  
- **Charts / Data Visualization** – `react-native-chart-kit`, `VictoryNative`, etc.  
- **Backend / API** – Firebase  
- **Other Tools** – Git, GitHub
